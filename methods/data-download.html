01

BEFORE DOWNLOAD

Selection freeze

다운로드 도중 대상을 바꾸지 않도록 확정된 image/series ID 목록에 버전을 부여하고 예상 파일 수를 기록합니다.

대상 목록

선택 규칙을 통과한 ID와 modality, 방문, acquisition 정보를 고정합니다.

접근 확인

승인된 ADNI 계정과 데이터 사용 조건을 확인하고 제한 자료의 저장 위치를 준비합니다.

02

CONTROLLED DOWNLOAD

실패를 추적할 수 있게 받습니다

  1. 01
    승인된 환경 사용

    개인정보와 접근 정보가 노출되지 않는 연구용 저장 위치에서 실행합니다.

  2. 02
    작업 단위 분리

    modality 또는 batch별로 나눠 실패 범위를 쉽게 확인합니다.

  3. 03
    실패 항목 기록

    재시도할 ID와 오류를 별도 로그에 남기고 성공 자료와 섞지 않습니다.

  4. 04
    완료 상태 고정

    완료 시각, selection version과 다운로드 결과 요약을 보관합니다.

03

INTEGRITY CHECK

다운로드 완료는 검사가 끝난 뒤입니다

COUNT

파일 수

예상 image/series 수와 실제 다운로드 결과를 비교합니다.

ARCHIVE

압축 상태

손상된 압축 파일과 불완전한 해제를 확인합니다.

STRUCTURE

영상 구조

DICOM/NIfTI 구성, 핵심 metadata와 누락 여부를 점검합니다.

DOWNLOAD LOG

download_manifest

대상 ID, 예상 파일, 완료 상태, 재시도 여부와 검사 결과를 기록합니다.

04

ORGANIZATION

원본과 파생 자료를 분리합니다

  • 원본 다운로드는 읽기 전용 또는 변경이 통제된 위치에 보관합니다.
  • BIDS 변환 자료와 전처리 산출물은 원본과 별도 경로에 둡니다.
  • 파일명에 직접식별정보나 개인 이름을 넣지 않습니다.
  • RID와 내부 subject ID 매핑은 접근 제한 위치에서 관리합니다.
