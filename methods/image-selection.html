02 · MULTIMODAL MATCHING

RS-fMRI + T1
이미지 선택

후보 영상을 모두 보존한 뒤 QC와 프로토콜을 검토해 대표 스캔을 선택하고 같은 방문의 두 modality를 페어링합니다.

DocumentedSame-visit pairing

이 페이지의 목차

먼저 후보를 모두 보존합니다선택 우선순위T1과 rs-fMRI의 교집합자동 규칙 밖의 사례최종 페어와 선택 로그
01

CANDIDATE INVENTORY

먼저 후보를 모두 보존합니다

한 방문에 같은 modality의 스캔이 여러 개 존재할 수 있으므로 검색 결과를 즉시 축약하지 않고 image·series metadata와 함께 후보 목록을 만듭니다.

SEQUENCE

Protocol

MPRAGE, IR-SPGR, resting-state EPI 등 허용한 sequence인지 확인합니다.

ACQUISITION

Parameters

field strength, multiband, TR, TE, voxel size와 volume 수를 기록합니다.

REPEAT

Duplicates

동일 방문 반복 촬영 여부와 각 run의 QC 결과를 함께 유지합니다.

02

DECISION RULE

선택 우선순위

  1. 01
    공식 QC

    PASS/FAIL 판정과 영상별 코멘트를 먼저 확인합니다.

  2. 02
    프로토콜 적합성

    sequence, field strength와 multiband 여부가 분석 설계에 맞는지 검토합니다.

  3. 03
    영상 품질

    motion, artifact, brain coverage와 유효 volume 수를 비교합니다.

  4. 04
    대표 이미지 ID

    사전에 정한 우선순위로 방문별 대표 스캔을 한 개 선택합니다.

03

SAME-VISIT MATCH

T1과 rs-fMRI의 교집합

STRUCTURAL

T1 MRI

해부학적 기준 영상과 structural phenotype 생성에 사용합니다.

FUNCTIONAL

Resting-state fMRI

기능적 시계열과 connectivity 분석의 입력입니다.

JOIN KEY

RID + PHASE + VISCODE

두 modality가 모두 존재하고 QC 기준을 통과한 방문만 최종 후보에 유지합니다.

RIDPHASEVISCODET1_IMAGE_IDRSFMRI_IMAGE_ID
04

EXCEPTIONS

자동 규칙 밖의 사례

  • Search 결과와 공식 QC가 충돌하면 QC 테이블과 영상별 코멘트를 우선 검토합니다.
  • 동일 방문 촬영이 없고 날짜 차이를 허용한다면 허용 범위를 사전에 명시합니다.
  • 프로토콜 혼합이 불가피하면 protocol 효과를 기록하고 분석 단계에서 다룹니다.
  • 모든 수동 판단은 제외·선택 사유와 검토자를 selection log에 기록합니다.
05

OUTPUTS

최종 페어와 선택 로그

pairing_summary

방문별 T1–rs-fMRI image ID 페어와 핵심 acquisition 정보를 보관합니다.

selection_log

선택 규칙, 제외 사유, 예외 판단과 QC 출처를 기록합니다.

!
공개 제한

실제 RID와 image ID가 결합된 선택 목록은 접근 제한 위치에 보관합니다.
