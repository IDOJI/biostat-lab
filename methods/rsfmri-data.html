02 · RS-fMRI DATA

RS-fMRI
데이터

영상 선택부터 다운로드, 전처리까지 한 흐름으로 정리합니다.

이 페이지의 목차

영상 선택과 T1 페어링데이터 다운로드전처리와 품질관리
01

IMAGE SELECTION

영상 선택과 T1 페어링

  1. 01
    후보 수집

    방문별 T1과 resting-state fMRI 후보 및 acquisition 정보를 보존합니다.

  2. 02
    대표 영상 선택

    공식 QC, 프로토콜, 움직임과 영상 품질을 기준으로 대표 스캔을 정합니다.

  3. 03
    같은 방문 연결

    RID, PHASE, VISCODE를 기준으로 T1과 rs-fMRI를 페어링합니다.

OUTPUT

selection_log · pairing_summary

선택된 image ID, 제외 사유, QC 출처와 최종 페어를 기록합니다.

02

DOWNLOAD

데이터 다운로드

  • 확정된 image ID 목록과 예상 파일 수를 먼저 고정합니다.
  • 승인된 환경에서 자료를 받고 실패 항목을 기록합니다.
  • 파일 수, 압축 상태, DICOM/NIfTI 구조와 metadata를 검사합니다.
  • 원자료와 접근 정보는 공개 저장소에 포함하지 않습니다.
03

PREPROCESSING & QC

전처리와 품질관리

Convert→Realignment→Coregistration→Normalization→Regression→Filtering
  • 소프트웨어, 버전, 파라미터와 실패 로그를 기록합니다.
  • framewise displacement, censoring 비율과 유효 volume을 확인합니다.
  • EPI–T1 정합, normalization, brain mask와 시계열을 시각적으로 검토합니다.
  • 전처리 영상, 분석용 시계열과 QC 보고서를 산출합니다.
