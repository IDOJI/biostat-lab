01

SCOPE

확정된 파이프라인만 공개합니다

현재 페이지는 SNP 전처리에서 문서화할 범위를 제시합니다. 실제 데이터 릴리스, genome build, 도구 버전과 임계값은 파이프라인 확정 후 추가합니다.

!
현재 상태

아래 항목은 일반적인 작업 단계이며, 실제 연구에서 사용한 구체적 threshold를 의미하지 않습니다.

02

SAMPLE-LEVEL QC

개체 수준 품질관리

Missingness

sample별 genotype call rate와 과도한 결측을 평가합니다.

Sex check

기록된 성별과 genotype 기반 추정의 불일치를 검토합니다.

Heterozygosity

이형접합도 분포에서 극단적인 sample을 확인합니다.

Relatedness

중복·근연 sample을 식별하고 분석 설계에 맞게 처리합니다.

03

VARIANT-LEVEL QC

변이 수준 품질관리

  • variant call rate와 결측률 기준을 사전에 고정합니다.
  • minor allele frequency 기준과 적용 목적을 기록합니다.
  • Hardy–Weinberg equilibrium 검사를 분석 집단에 맞게 적용합니다.
  • allele, strand, position과 genome build의 일관성을 확인합니다.
04

STRUCTURE & IMPUTATION

Population structure와 분석 세트

  1. 01
    Ancestry와 principal components

    population structure를 평가하고 분석 공변량 생성 방법을 기록합니다.

  2. 02
    Phasing·imputation

    reference panel, 도구와 버전, 품질 기준을 명시합니다.

  3. 03
    Post-imputation QC

    imputation quality, MAF와 변이 일치 여부를 재검토합니다.

05

COHORT LINKAGE

영상 코호트와 연결

SNP sample과 영상 subject의 매핑 규칙, 불일치 처리와 최종 교집합을 명확히 기록합니다.

Internal mapping

민감한 ID 매핑표는 접근 제한 위치에서 관리합니다.

Analysis cohort

유전체 QC와 영상 QC를 모두 통과한 subject 교집합을 생성합니다.
